## 1. 实验目标

本实验面向 `.docx` 文档自动处理场景，实现一个基于 Linux、Python 与 FastAPI 的文档结构提取和样式替换系统。系统能够读取给定 `.docx` 文件，识别标题、正文、表格等主要结构，输出文档树 JSON，并按照预定义 style 配置替换文档中的相关结构样式。

## 2. 技术路线

`.docx` 本质上是一个 ZIP 包，正文内容位于 `word/document.xml`，样式定义通常位于 `word/styles.xml`。本项目直接解析 Office Open XML：

- 从 `document.xml` 中读取段落、标题与表格。
- 从 `styles.xml` 中建立 style id 与 style name 的映射。
- 通过标题样式、中文标题样式和 `outlineLvl` 判断文档层级。
- 将段落挂载到最近的标题节点下，形成树形结构。
- 按 `config/predefined_styles.json` 将结构节点样式统一替换。

## 3. 系统模块

### 3.1 核心解析模块

`docx_style_tree.extractor` 提供 `analyze_docx` 函数。输入可以是文件路径、字节数据或二进制流，输出包含：

- `format`：文档格式。
- `node_count`：文档树节点数量。
- `tree`：文档树根节点。

树节点包含标题、层级、样式 id、样式名称、内容块和子节点。

### 3.2 样式替换模块

`docx_style_tree.style_replacer` 提供 `replace_styles` 函数。系统会遍历所有段落，根据标题层级或正文类型选择 style map key，例如：

- `heading_1`
- `heading_2`
- `heading_3`
- `normal`

然后将段落的 `w:pStyle` 改写为目标 style id，最后重新打包为 `.docx` 文件。

### 3.3 FastAPI 服务

FastAPI 应用位于 `app/main.py`，提供以下接口：

- `GET /health`：健康检查。
- `POST /api/tree`：上传 `.docx` 并返回文档树 JSON。
- `POST /api/style`：上传 `.docx` 并返回替换样式后的 `.docx`。

### 3.4 命令行工具

`cli.py` 支持在无 Web 服务环境下直接运行：

```bash
python3 cli.py analyze input.docx -o tree.json
python3 cli.py style input.docx -o styled.docx
```

## 4. 运行方法

```bash
uv python install 3.11
uv sync
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

浏览器访问 `http://127.0.0.1:8000/docs` 即可使用 Swagger UI 调试接口。

## 5. 测试方法

uv run python -m unittest discover -s tests

测试内容覆盖：

- DOCX 文档树提取。
- 标题层级识别。
- 结构样式替换。
